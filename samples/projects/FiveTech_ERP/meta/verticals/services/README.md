# Vertical pack: services

Professional services / consulting demo.

Loaded when `app.vertical` is `"services"` (Edit app → Vertical pack, or `meta/app.json`).

## Menu focus

- **CRM** — clients, accounts, pipeline (core)
- **Delivery** — projects, project card, timesheets, work orders
- **Commercial** — quotes, invoices, service catalog
- **Admin** — KPIs, params, users

## Screens / data (base meta)

| Screen | Data |
|--------|------|
| `screen.projects` | `data.projects` |
| `screen.project_card` | `data.projects` |
| `screen.timesheets` | `data.timesheets` |

Plus shared CRM / quotes / invoices.
