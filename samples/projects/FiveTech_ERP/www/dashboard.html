Dashboard widgets

Type Id Title Span Tone dataRef Options Order

Widget types: kpi (metric tile), bar (grouped columns), donut (share pie), text (note). Span is width on a 12-column grid (e.g. 3 = quarter, 4 = third, 8+4 = chart row). Tone sets the coloured top border: info · ok · warn · danger · purple · teal. Options are key=value pairs separated by ; — kpi: row=k1;format=money;subtitle=Atualizado agora or static value=0;format=money; bar: cat=month;height=180;series=capital:Capital:#16a34a,loans:Loans:#2563eb; donut: label=label;value=value;color=color;center=Carteira. Leave the widget list empty to auto-tile every row of the screen dataRef (legacy).
