# Vertical pack: retail

Retail / POS store demo.

Loaded when `app.vertical` is `"retail"`.

## Menu focus

- **Customers** — parties as customers, segments, follow-ups
- **Store** — products, stock, POS tickets
- **Back office** — invoices, B2B quotes, CSV import
- **Admin** — dashboard, cashiers/roles, company/store

## Screens / data (base meta)

| Screen | Data |
|--------|------|
| `screen.products` | `data.products` |
| `screen.stock` | `data.stock` |
| `screen.pos_sales` | `data.pos_sales` |
